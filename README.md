# Поиск референсных изображений по текстовому описанию (PoC)

## Описание проекта
Разработка демонстрационной версии (Proof of Concept) поискового сервиса для фотохостинга.
Сервис должен находить изображения, наиболее соответствующие текстовому запросу пользователя, выдавая оценку схожести от 0 до 1.

## Основные задачи
1. **Подготовка данных**: Агрегация экспертных и краудсорсинговых оценок, очистка от запрещенного контента.
2. **Векторизация**:
   - Изображения: Использование предобученной CNN (ResNet50).
   - Текст: Векторизация через TF-IDF / Word2Vec / BERT.
3. **Обучение модели**: Построение регрессионной модели (Linear Regression / MLP) с подбором гиперпараметров для предсказания оценки соответствия.
4. **Тестирование**: Демонстрация работы поиска на тестовых запросах с учетом юридических ограничений.

## Юридические ограничения
Согласно законодательству ряда стран, сервис запрещает обработку контента с изображением или описанием детей (лиц младше 16 лет) без согласия представителей.
- **Решение в PoC**:
  - Исключение таких пар (изображение-текст) из обучающей выборки.
  - Возврат дисклеймера при поисковом запросе, содержащем ключевые слова, указывающие на детей.

## Описание данных
Проект использует следующие данные (предполагается наличие папки `data/`):
- `train_dataset.csv`: Пары изображение-текст для обучения.
- `CrowdAnnotations.tsv`: Оценки соответствия от краудсорсинга.
- `ExpertAnnotations.tsv`: Оценки соответствия от трех экспертов (шкала 1–4).
- `test_queries.csv`: Тестовые запросы для демонстрации работы.
- `train_images/`, `test_images/`: Папки с изображениями.

### 2. Извлечение признаков
Для каждой пары (запрос, изображение) формируются два вектора признаков, которые затем конкатенируются:
* **Эмбеддинги текста** — извлекаются предобученной моделью BERT (представление CLS-токена из последнего скрытого слоя, максимальная длина последовательности — 128 токенов).
* **Эмбеддинги изображений** — извлекаются предобученной моделью ResNet-18 (без последнего классификационного слоя).

Эмбеддинги кэшируются на диск для ускорения повторных запусков.

### 3. Моделирование
* Разделение выборки с помощью `GroupShuffleSplit` (группировка по `image`, `train_size=0.7`).
* Обучение и сравнение трёх моделей:
  * `LinearRegression` — базовая модель (baseline).
  * `Ridge` — гребневая регрессия с подбором гиперпараметра `alpha` через `GridSearchCV` и валидацией по `GroupKFold` (5 фолдов).
  * Полносвязная нейронная сеть (`MLP`) на PyTorch с функцией активации `Sigmoid` на выходном слое и механизмом ранней остановки (`early stopping`, `patience=10`).

Основная метрика качества — **RMSE**.

## Результаты и метрики

| Модель                | RMSE (валидация) |
|:----------------------|:----------------:|
| Линейная регрессия    |     0.2401       |
| Ridge Regression      |     0.2151       |
| Нейросеть (MLP)       |     0.2050       |

**Лучшая модель**: полносвязная нейронная сеть показала наименьшую ошибку на валидационной выборке. При тестировании на отложенной выборке RMSE составил 0.29.
